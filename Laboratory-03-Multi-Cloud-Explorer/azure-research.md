# Microsoft Azure Research

## Brief Overview
Microsoft Azure, launched in 2010, is a public cloud computing platform operated by Microsoft. It provides a wide range of services including compute, analytics, storage, and networking, with particularly deep native integration for Windows-centric enterprise software environments.

## Global Infrastructure
Azure features a robust global network spanning more than 60 regions worldwide, organized into availability zones for high availability, backed by Microsoft's extensive private global optical fiber network.

## Cloud Management Console
The Azure Portal is a unified web-based application that provides a dashboard to manage everything from simple web apps to complex cloud deployments.

## Four (4) Core Services
1. **Azure Virtual Machines (VMs):** On-demand, scalable computing resources running Windows or Linux.
2. **Azure Blob Storage:** Microsoft's object storage solution for massive unstructured data storage.
3. **Azure SQL Database:** Fully managed relational database engine built on the SQL Server engine.
4. **Azure Active Directory (Microsoft Entra ID):** Cloud-based identity and access management service.

## Three (3) Advantages
1. **Seamless Hybrid Cloud Integration:** Unmatched capabilities for connecting on-premises data centers (via Azure Arc, ExpressRoute) with cloud resources.
2. **Enterprise Microsoft Alignment:** Flawless compatibility with existing Windows Server, Active Directory, SQL Server, and Microsoft 365 investments.
3. **Enterprise Agreements and Licensing:** Favorable licensing structures and discount models for organizations heavily invested in Microsoft enterprise software.

## Typical Enterprise Use Cases
● **Hybrid Cloud Environments:** Extending active on-premises Windows server setups safely into the cloud.
● **Enterprise Identity Management:** Centralizing user credentials and single sign-on (SSO) across enterprise applications.
● **.NET Application Hosting:** Developing, testing, and deploying enterprise web apps using native Microsoft tech stacks (.NET, Visual Studio).
