## Comparative Analysis Questions

1. **Which cloud provider offers the broadest range of services?**  
   Amazon Web Services (AWS) offers the widest and most mature portfolio of specialized cloud services due to its years of early market leadership and continuous expansion into niche technological domains.

2. **Which provider best integrates with Microsoft technologies?**  
   Microsoft Azure provides the most frictionless integration with traditional Microsoft environments, making it seamless to connect existing Active Directory, SQL Server, and Windows Server systems to the cloud.

3. **Which provider is strongest in Artificial Intelligence and Kubernetes?**  
   Google Cloud Platform (GCP) holds a distinct advantage in these areas because Google originally created Kubernetes and leads the industry in advanced data analytics and AI infrastructure like BigQuery and Vertex AI.

4. **Which cloud platform would you personally choose and why?**  
   I would choose AWS for general-purpose enterprise applications due to its extensive documentation, massive community support, and reliable stability, though I would lean toward GCP if the project's core focus heavily involved modern container orchestration or machine learning workflows.
